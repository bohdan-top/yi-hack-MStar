# FW-007.1 — minimum security tests

- Status: Planned
- Milestone: 0.1.0
- Priority: P0
- Dependencies: FW-002; FW-003
- Target: y203c / 6FUS

## Scope

Create isolated tests for CGI path validation, traversal rejection, unsafe config keys, password parsing, expected valid requests, auth defaults and service enablement. Use disposable fixtures and mocked destructive commands; no destructive probes against the physical camera. Add config migration and upgrade integrity tests; record skipped/unsupported cases.

## Acceptance criteria

Runnable documented local test command, negative and positive cases, exit code on failure, reviewable sanitized report. Every critical mitigation has a test or an explicit hardware-only gate.

## Deliverables

Implementation PR (where applicable), test commands and results, sanitized evidence, residual risks and explicit NOT VERIFIED items. Link back to the [roadmap](../docs/firmware-roadmap.md). No device changes without explicit owner approval.
