# FW-007.1 — minimum security tests

- Status: Planned
- Milestone: 0.1.0
- Priority: P0
- Dependencies: FW-002; FW-003; FW-008
- Target: y203c / 6FUS

## Scope

Create isolated tests for CGI path validation, traversal rejection, unsafe config keys, password parsing, expected valid requests, auth defaults and service enablement. Use disposable fixtures and mocked destructive commands; no destructive probes against the physical camera. Integrate the suite into the FW-008 manual pipeline so failures block the release gate. Add fail-closed configuration tests for missing, empty, malformed, truncated, duplicate and legacy keys, including restored settings. Define upgrade-integrity negative tests (wrong target, corrupted/untrusted archive, unexpected paths and interrupted staging); tests needing the FW-012 implementation may be specified here and executed in FW-012 rather than creating a circular dependency. Record skipped/unsupported cases.

## Acceptance criteria

Runnable documented local test command, negative and positive cases, exit code on failure, reviewable sanitized report. Every critical mitigation has a test or an explicit hardware-only gate. No skipped mandatory software test counts as a pass; FW-012 reruns the suite against the final candidate.

## Deliverables

Implementation PR (where applicable), test commands and results, sanitized evidence, residual risks and explicit NOT VERIFIED items. Link back to the [roadmap](../docs/firmware-roadmap.md). No device changes without explicit owner approval.
